# 🏊‍♂️ Proyecto Final: Pasión por la Natación

Este repositorio contiene la versión final de mi página web para el modulo 2. Es una evolución completa del proyecto del Módulo 1, donde he integrado **CSS3 avanzado** para transformar una estructura HTML básica en una experiencia web moderna, visual y totalmente responsiva.

## 📝 Descripción del Proyecto

El objetivo de este entregable fue aplicar estilos y maquetación profesional al contenido previamente creado sobre la **Natación**. La página ya no es solo texto plano; ahora cuenta con una identidad visual definida, navegación fluida y una distribución de contenido dinámica.

### 🚀 Nuevas Características Implementadas

Siguiendo los requerimientos del proyecto final, he incorporado:

* **Diseño Responsivo (Responsive Design):** La página se adapta a diferentes tamaños de pantalla (móviles, tablets y escritorio) mediante el uso de `Media Queries`.
* **CSS Grid Layout:** Utilizado en las secciones de *"Estilos de Natación"* y *"Mis Ídolos"* para crear rejillas de tarjetas organizadas y estéticas.
* **Flexbox:** Implementado en la barra de navegación (`Navbar`) y la sección de *"Beneficios"* para una alineación y distribución flexible de los elementos.
* **Navegación Interactiva:**
    * Barra de navegación fija (`sticky`) en la parte superior.
    * Efecto de desplazamiento suave (`scroll-behavior: smooth`) al navegar entre secciones.
* **Estilizado Visual:**
    * Uso de tipografía `Roboto` vía Google Fonts.
    * Paleta de colores consistente (Azules profundos y acentos en naranja).
    * Efectos `Hover` en botones, enlaces e imágenes para mejorar la experiencia de usuario.
    * Fondo con imagen en el `Header` con superposición (overlay) para mejorar la legibilidad del texto.

## 📂 Estructura del Proyecto

El proyecto mantiene las buenas prácticas de separación de responsabilidades:

* `index.html`: Estructura semántica (HTML5) con etiquetas como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* `styles.css`: Hoja de estilos externa que contiene todas las reglas de diseño, variables y media queries.

## 📖 Secciones del Sitio

1.  **Inicio:** Banner principal con llamada a la acción ("Hero Section").
2.  **Estilos:** Grid visual explicando los 4 estilos (Crol, Dorso, Pecho, Mariposa).
3.  **Beneficios:** Tarjetas informativas sobre salud física y mental.
4.  **Mi Historia:** Una sección personal sobre mi trayectoria desde el aprendizaje empírico hasta la natación universitaria.
5.  **Ídolos:** Galería de nadadores referentes mundiales.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Estilos, animaciones y maquetación.
* **Git & GitHub:** Control de versiones y despliegue.
